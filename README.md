# UNP_PROJECT_E-COMMERCE-DATA-ANALYSIS_USING_MYSQL

My project is an e-commerce database system designed to manage customers, products, orders, and payments. It stores customer details, product information with pricing and discounts, and tracks orders with their status like delivered or pending. It also records different payment methods and their status. Overall, the system helps in organizing sales data, analyzing revenue, and understanding customer and payment trends efficientl
